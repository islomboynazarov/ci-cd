Setting up CI/CD taught me that automation is not about writing less code but about writing instructions that make the process reliable — configuring GitHub Actions to automatically lint, test, build, and deploy on every push meant that every change was validated without manual effort, and when things broke (which they did, repeatedly, with GitHub Pages failing to publish even when the build succeeded), the logs made it clear exactly where the failure happened, which is the whole point of CI/CD — not preventing failures but making them visible and traceable immediately.
